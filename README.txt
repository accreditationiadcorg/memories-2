نسخة Static من الموقع — لا تحتاج PHP.

طريقة الصور:
- كل الصور موجودة داخل مجلد photos فقط.
- اسم الملف هو الذي يحدد الألبوم والصورة:
  01-اول مغامرة__01.jpg
  01-اول مغامرة__02.jpg
  01-اول مغامرة__cover.jpg
- __cover اختيارية وتستخدم كغلاف للألبوم.
- الصور العادية هي __01, __02, __03 ...

لإضافة أو حذف صور:
1) ضع الصور داخل photos.
2) استخدم نفس نظام التسمية.
3) شغّل generate-manifest.py لتحديث photos.js.
4) ارفع الملفات إلى GitHub Pages أو أي Static Hosting.

مهم:
المتصفح لا يستطيع تعداد ملفات المجلد تلقائياً على الاستضافات Static، لذلك photos.js هو فهرس ثابت لأسماء الملفات. لا يوجد PHP أو API.
